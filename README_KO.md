# ScanBox PWA v1.1.6

아이폰 Safari / 홈 화면 PWA에서 문서를 촬영하거나 사진을 불러와 문서 보정, OCR, 검색 가능한 PDF, JPG/PNG 저장을 수행하고, 별도 **PDF 편집** 탭에서 기존 PDF의 페이지 구조를 정리하는 개인용 앱입니다.

v1.1.6은 v1.1.5의 실제 문서 외곽 검출과 seamless 원근 보정을 유지하면서 **페이지 관리 / PDF 페이지 크기 / 다국어 OCR / PDF 구조 편집**을 크게 확장한 버전입니다.

## v1.1.6 핵심 변경

### 스캔 페이지 관리
- 여러 사진을 한 번에 불러온 뒤 상단 `페이지 순서` 썸네일에서 바로 확인할 수 있습니다.
- 썸네일을 손가락으로 끌어 순서를 변경할 수 있습니다.
- `순서` 번호를 직접 입력해 원하는 위치로 이동할 수 있습니다.
- 썸네일에서 불필요한 페이지를 즉시 삭제할 수 있습니다.
- 기존 상세 페이지 카드의 드래그 순서 변경도 유지합니다.

### PDF 페이지 크기
PDF 저장 시 다음 세 가지를 선택할 수 있으며 **가장 최근 선택을 기억**합니다.

- `사진에 맞춤`: 스캔 이미지 종횡비를 PDF 페이지 비율로 그대로 사용합니다. 흰 여백과 이미지 왜곡이 없습니다.
- `A4`: A4 규격 페이지 전체를 채웁니다. 여백은 만들지 않으며 스캔 이미지가 A4 비율로 정규화됩니다.
- `A3`: A3 규격 페이지 전체를 채웁니다. 여백은 만들지 않으며 스캔 이미지가 A3 비율로 정규화됩니다.

화면 보관 / 전자문서 용도는 `사진에 맞춤`, 실제 규격 인쇄가 중요하면 A4/A3를 권장합니다.

### OCR 언어
OCR을 켠 경우 `KOR / ENG / CHI`를 각각 독립적으로 선택할 수 있고 마지막 선택을 기억합니다.

- KOR → `kor`
- ENG → `eng`
- CHI → `chi_tra` (번체 중국어 모델, 한자 문서 보조)

OCR 언어는 최소 1개 이상 선택해야 합니다. 선택한 언어 모델만 실제 OCR 작업에 로드합니다.

### OCR 텍스트 교정
`OCR 확인` 화면의 인식 텍스트를 직접 수정한 뒤 `OCR 수정 적용`을 누르면 검색 PDF의 **검색용 텍스트 레이어**에 교정 내용이 반영됩니다.

- 화면에 보이는 스캔 이미지는 변경하지 않습니다.
- 교정한 페이지는 좌표 기반 단어 레이어 대신 교정 텍스트를 숨김 검색 레이어로 저장합니다.

### PDF 편집 탭
기존 스캔 탭의 PDF 편집과 `이미지 → PDF` 변환 기능을 제거하고 별도 **PDF 편집** 탭으로 정리했습니다.

지원 기능:
- PDF 여러 개 추가 / 합치기
- 페이지 썸네일 확인
- Drag & Drop 순서 변경
- 번호 입력으로 순서 이동
- 개별 페이지 삭제
- 다중 선택
- 선택 페이지 추출
- 범위별 PDF 나누기 (`1-3, 4-6, 7` 형태)
- 여러 분할 결과 ZIP 저장
- PDF → JPG / PNG
- 선택한 페이지의 기존 OCR/검색 텍스트 추출 및 수정

합치기 / 재정렬 / 삭제 / 추출 / 나누기는 `pdf-lib`로 **원본 PDF 페이지 객체를 복사**합니다. 따라서 단순히 페이지를 이미지로 바꿨다가 다시 만드는 방식보다 원본 텍스트와 벡터 요소를 더 잘 보존합니다.

단, 디지털 서명, 일부 폼/주석/문서 수준 메타데이터 등은 페이지 복사 과정에서 그대로 유지되지 않을 수 있습니다.

PDF 편집 탭에서 `OCR 텍스트 수정`을 적용한 페이지는 검색 레이어를 다시 만들기 위해 해당 페이지만 고해상도 이미지로 재렌더링합니다. 따라서 그 페이지의 원본 벡터 구조 보존이 더 중요하면 OCR 텍스트 수정 기능을 사용하지 마세요.

## 보안 / 개인정보

문서, 사진, OCR 결과, 생성 PDF를 ScanBox 서버로 업로드하는 기능은 없습니다. 문서 데이터는 브라우저 내부 메모리에서 처리합니다.

인터넷은 고정 버전 실행 엔진을 준비하는 데 사용됩니다.

- OpenCV.js 5.0.0
- Tesseract.js 7.0.0 / tesseract.js-core 7.0.0
- KOR / ENG / CHI OCR 언어 데이터
- PDF.js 6.3.289
- pdf-lib 1.17.1

JSZip 3.10.1은 ZIP 안에 로컬 포함되어 있습니다. 스캔 PDF 생성은 자체 `pdf-engine.js`를 사용합니다.

외부 실행 파일은 HTML에서 바로 실행하지 않고 다음 방식으로 준비합니다.

1. 고정 버전 jsDelivr URL에서 HTTPS 다운로드
2. 허용 호스트 / redirect 최종 목적지 검사
3. SHA-256 계산
4. 앱 버전별 최초 지문 잠금(TOFU)
5. 같은 출처의 앱 전용 Cache Storage에 저장
6. 이후 캐시 사본 실행
7. 같은 버전 URL의 내용이 잠근 SHA-256과 다르면 실행 중단

**TOFU 한계:** 최초 다운로드 자체가 이미 변조된 경우까지 독립적으로 검증하는 사전 등록 해시 방식은 아닙니다.

## 보안 · 오프라인 준비

`설정 → 보안 · 오프라인 준비`를 실행하면 현재 선택된 OCR 언어 모델과 PDF/OCR 실행 엔진을 준비합니다. 나중에 아직 준비하지 않은 OCR 언어(CHI 등)를 새로 선택하면 해당 모델은 처음 사용할 때 인터넷으로 한 번 준비됩니다.

업데이트 시 Service Worker가 이전 `scanbox-*` Cache Storage를 삭제하고, 이전 버전의 보안 지문 / 준비 기록도 정리합니다. 버전마다 대용량 엔진이 계속 누적되는 구조가 아닙니다.

## 입력 보호 한도

- 이미지 1개 최대 40 MB
- PDF 1개 최대 120 MB
- 한 번에 선택한 파일 총량 최대 약 200 MB
- 한 작업 최대 100 페이지
- PDF → 다중 이미지 ZIP 최대 60 페이지
- 캔버스 약 2,000만 픽셀 상한
- 이미지 최대 한 변 12,000 px / 약 5,000만 픽셀 사전 검사
- PDF 분석 / 렌더링 개별 작업 30초 제한
- SVG 이미지 입력 차단

## v1.1.5 → v1.1.6 업데이트

1. `ScanBox-PWA-v1.1.6.zip`을 압축 해제합니다.
2. 기존 GitHub Pages 저장소에 **폴더 안의 파일과 폴더 전체**를 같은 경로로 업로드해 덮어씁니다.
3. GitHub Pages 배포가 완료되면 iPhone Safari에서 Pages 주소를 한 번 직접 엽니다.
4. 화면 상단이 `ScanBox 1.1.6`인지 확인합니다.
5. 홈 화면 ScanBox를 완전히 종료한 뒤 다시 실행합니다.
6. `설정 → 보안 · 오프라인 준비`를 한 번 실행합니다.
7. `완료 ✓ · 다시 확인`이 나타나면 준비 완료입니다.

계속 이전 버전이 보이면 Safari에서 Pages 주소를 새로고침한 뒤 홈 화면 앱을 다시 실행하세요. 그래도 갱신되지 않으면 홈 화면 아이콘만 삭제하고 Pages 주소에서 다시 `홈 화면에 추가`하면 됩니다. GitHub 저장소의 파일은 삭제되지 않습니다.

## 제한 사항

- 브라우저 기반 OCR은 네이티브/서버 OCR과 정확도가 다를 수 있습니다.
- `CHI`는 한국 한자 전용 모델이 아니라 `chi_tra` 번체 중국어 문자 모델입니다.
- 임시 작업 자동 저장은 하지 않습니다. 앱 종료/새로고침 전에 결과 파일을 저장하세요.
- PDF 구조 편집은 암호화 PDF나 일부 손상/특수 PDF를 지원하지 못할 수 있습니다.
- PDF 페이지 객체 복사는 디지털 서명이나 모든 문서 수준 기능의 보존을 보장하지 않습니다.
