# ScanBox PWA v1.1.8

아이폰 Safari / 홈 화면 PWA와 Android Chrome에서 문서를 촬영하거나 사진을 불러와 문서 보정, OCR, 검색 가능한 PDF, JPG/PNG 저장을 수행하고, 별도 **PDF 편집** 탭에서 기존 PDF의 페이지 구조를 정리하는 개인용 앱입니다.

v1.1.8은 v1.1.7의 스캔·OCR·PDF 편집 기능을 유지하면서 **빈 작업 화면을 정리하고 PDF 페이지 재배열 및 PDF → 이미지 회전 미리보기를 강화한 UI 개선 버전**입니다.

## v1.1.8 핵심 변경

- 스캔 문서가 0장일 때 `페이지` 영역을 완전히 숨기고, 촬영/사진 불러오기 후에만 표시합니다.
- PDF 편집도 PDF가 없을 때 편집 작업 영역을 숨기고 `PDF 추가` 진입점만 표시합니다. PDF를 추가하면 페이지 목록·편집·나누기 UI가 나타납니다.
- PDF 편집 각 페이지에 `≡` 전용 손잡이를 추가해 손가락/마우스로 위아래 Drag & Drop 순서 변경을 명확하게 지원합니다. 긴 목록에서는 화면 가장자리 드래그 시 자동 스크롤을 보조합니다.
- `PDF → 이미지`는 파일 선택 즉시 변환하지 않고 **페이지 미리보기 → 페이지별 좌/우 90° 회전 → JPG/PNG 저장** 순서로 동작합니다. 원본 PDF는 변경하지 않습니다.

### 스캔 페이지 조작
- 별도 `페이지 순서` 썸네일 영역을 제거했습니다.
- 각 페이지의 `≡` 손잡이를 누른 채 위아래로 끌어 순서를 변경합니다.
- 페이지 제목을 `[1] 페이지` 형식으로 바꾸고 대괄호 안 숫자를 수정하면 해당 순서로 즉시 이동합니다.
- 페이지 이미지를 누르면 현재 **영역 보정 / 회전 / 필터가 적용된 결과를 크게 미리보기**할 수 있습니다.
- 미리보기에서 이전 / 다음 페이지 이동과 좌우 스와이프를 지원합니다.
- `삭제`는 일반 편집 버튼과 분리하고 빨간색 위험 버튼으로 표시했습니다.

### 스캔 필터 단순화
스캔 필터는 세 가지로 줄였습니다.
- `컬러`: 보정된 사진의 색을 그대로 유지합니다.
- `흑백`: 노출 보정 없이 단순 회색조 필터만 적용합니다.
- `문서`: 기존 문서 모드처럼 배경을 밝게 하고 글자 대비를 높여 문서형 결과를 만듭니다.

### PDF 페이지 크기
마지막 선택을 기억합니다.
- `사진에 맞춤`: 스캔 이미지 종횡비를 PDF 페이지 비율로 사용해 흰 여백과 왜곡을 만들지 않습니다.
- `A3` 297 × 420 mm
- `A4` 210 × 297 mm
- `A5` 148 × 210 mm
- `B4` 257 × 364 mm
- `B5` 182 × 257 mm
- `Letter` 216 × 279 mm
- `Legal` 216 × 356 mm

규격 페이지를 선택하면 해당 페이지 전체를 채우므로 스캔 이미지와 규격 비율이 조금 다를 경우 미세한 비율 정규화가 발생할 수 있습니다.

### OCR
- OCR은 스캔 탭에서만 설정합니다. 설정 탭의 중복 OCR 언어 표시를 삭제했습니다.
- `KOR / ENG / CHI`를 각각 독립적으로 선택할 수 있고 마지막 선택을 기억합니다.
- CHI는 `chi_tra` 번체 중국어 모델을 사용해 한자 문서를 보조합니다.
- OCR 텍스트 교정은 검색 PDF의 숨김 텍스트 레이어만 수정하며 보이는 스캔 글자는 바꾸지 않습니다.

### PDF 편집
- PDF 여러 개 추가 / 합치기
- 페이지 Drag & Drop / 번호 이동
- 다중 선택 / 삭제 / 선택 추출
- 범위별 PDF 나누기
- PDF → JPG / PNG: 페이지 미리보기 + 페이지별 좌/우 90° 회전
- PDF가 없을 때 편집 작업 영역 숨김, PDF 추가 후 자동 표시
- 선택 페이지 OCR 검색 텍스트 교정
- 빈 화면의 기울어진 `PDF` 표시를 제거하고 안내 문구를 간결하게 정리했습니다.

## 보안 · 오프라인 준비

같은 ScanBox 버전과 같은 기기에서는 **한 번 준비가 완료되면 반복 다운로드할 필요가 없습니다.** 새 버전으로 업데이트했거나 브라우저가 사이트 데이터를 정리했거나 OCR 언어 구성을 새로 바꾼 경우에 다시 준비하면 됩니다.

보안 준비 시 고정 버전 실행 엔진을 HTTPS로 내려받고 SHA-256 지문을 잠근 뒤 앱 전용 캐시에 저장합니다. 문서 이미지, OCR 결과, 생성 PDF를 ScanBox 서버로 업로드하는 기능은 없습니다.

## Galaxy / Android에 공유

사용 중인 GitHub Pages ScanBox 주소를 친구에게 그대로 공유하면 됩니다. Galaxy의 Chrome에서 주소를 연 뒤 `⋮ → 홈 화면에 추가` 또는 `앱 설치`를 선택합니다. 친구 기기에서도 최초 1회 `보안 · 오프라인 준비`를 실행해야 하며, 사용자님의 문서 데이터나 캐시는 서로 공유되지 않습니다.

## 보안 / 개인정보


문서, 사진, OCR 결과, 생성 PDF를 ScanBox 서버로 업로드하는 기능은 없습니다. 문서 데이터는 브라우저 내부 메모리에서 처리합니다.

인터넷은 고정 버전 실행 엔진을 준비하는 데 사용됩니다.

- OpenCV.js 5.0.0
- Tesseract.js 7.0.0 / tesseract.js-core 7.0.0
- KOR / ENG / CHI OCR 언어 데이터
- PDF.js 6.3.289
- pdf-lib 1.17.1

JSZip 3.10.1은 ZIP 안에 로컬 포함되어 있습니다. 스캔 PDF 생성은 자체 `pdf-engine.js`를 사용합니다.

외부 실행 파일은 HTML에서 바로 실행하지 않고 다음 방식으로 준비합니다.

1. 고정 버전 jsDelivr URL에서 HTTPS 다운로드
2. 허용 호스트 / redirect 최종 목적지 검사
3. SHA-256 계산
4. 앱 버전별 최초 지문 잠금(TOFU)
5. 같은 출처의 앱 전용 Cache Storage에 저장
6. 이후 캐시 사본 실행
7. 같은 버전 URL의 내용이 잠근 SHA-256과 다르면 실행 중단

**TOFU 한계:** 최초 다운로드 자체가 이미 변조된 경우까지 독립적으로 검증하는 사전 등록 해시 방식은 아닙니다.

## 보안 · 오프라인 준비

`설정 → 보안 · 오프라인 준비`를 실행하면 현재 선택된 OCR 언어 모델과 PDF/OCR 실행 엔진을 준비합니다. 나중에 아직 준비하지 않은 OCR 언어(CHI 등)를 새로 선택하면 해당 모델은 처음 사용할 때 인터넷으로 한 번 준비됩니다.

업데이트 시 Service Worker가 이전 `scanbox-*` Cache Storage를 삭제하고, 이전 버전의 보안 지문 / 준비 기록도 정리합니다. 버전마다 대용량 엔진이 계속 누적되는 구조가 아닙니다.

## 입력 보호 한도

- 이미지 1개 최대 40 MB
- PDF 1개 최대 120 MB
- 한 번에 선택한 파일 총량 최대 약 200 MB
- 한 작업 최대 100 페이지
- PDF → 다중 이미지 ZIP 최대 60 페이지
- 캔버스 약 2,000만 픽셀 상한
- 이미지 최대 한 변 12,000 px / 약 5,000만 픽셀 사전 검사
- PDF 분석 / 렌더링 개별 작업 30초 제한
- SVG 이미지 입력 차단

## v1.1.7 → v1.1.8 업데이트

1. `ScanBox-PWA-v1.1.8.zip`을 압축 해제합니다.
2. 기존 GitHub Pages 저장소에 **폴더 안의 파일과 폴더 전체**를 같은 경로로 업로드해 덮어씁니다.
3. GitHub Pages 배포가 완료되면 iPhone Safari에서 Pages 주소를 한 번 직접 엽니다.
4. 화면 상단이 `ScanBox 1.1.8`인지 확인합니다.
5. 홈 화면 ScanBox를 완전히 종료한 뒤 다시 실행합니다.
6. `설정 → 보안 · 오프라인 준비`를 한 번 실행합니다.
7. `완료 ✓ · 다시 확인`이 나타나면 준비 완료입니다.

계속 이전 버전이 보이면 Safari에서 Pages 주소를 새로고침한 뒤 홈 화면 앱을 다시 실행하세요. 그래도 갱신되지 않으면 홈 화면 아이콘만 삭제하고 Pages 주소에서 다시 `홈 화면에 추가`하면 됩니다. GitHub 저장소의 파일은 삭제되지 않습니다.

## 제한 사항

- 브라우저 기반 OCR은 네이티브/서버 OCR과 정확도가 다를 수 있습니다.
- `CHI`는 한국 한자 전용 모델이 아니라 `chi_tra` 번체 중국어 문자 모델입니다.
- 임시 작업 자동 저장은 하지 않습니다. 앱 종료/새로고침 전에 결과 파일을 저장하세요.
- PDF 구조 편집은 암호화 PDF나 일부 손상/특수 PDF를 지원하지 못할 수 있습니다.
- PDF 페이지 객체 복사는 디지털 서명이나 모든 문서 수준 기능의 보존을 보장하지 않습니다.
