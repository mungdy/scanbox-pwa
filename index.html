ScanBox 1.1.9

가볍게 알아두면 좋은 사용법입니다.

1. 촬영

자동 보정이 켜져 있으면 문서 테두리를 찾아 원근을 보정합니다. 결과가 마음에 들지 않으면 각 페이지의 ‘영역 조정’에서 네 모서리를 직접 옮길 수 있습니다.

2. 정리

스캔 페이지의 ≡ 손잡이를 끌거나 [번호] 페이지의 숫자를 바꿔 순서를 정리할 수 있습니다. 페이지 이미지를 누르면 편집된 모습을 크게 미리 볼 수 있습니다. PDF 편집 탭에서도 ≡ 손잡이를 끌어 페이지 순서를 바꿀 수 있습니다.

3. OCR · 검색 PDF

OCR은 기본 OFF이며 마지막 선택을 기억합니다. KOR / ENG / CHI를 독립 선택할 수 있고 OCR 텍스트를 교정해 검색 PDF에 반영할 수 있습니다.

4. PDF → 이미지

PDF를 선택하면 페이지를 미리보고 좌우 90° 회전한 뒤 JPG/PNG로 저장할 수 있습니다. 페이지별 회전은 이미지 출력에만 적용됩니다.

5. 저장

파일을 만든 뒤 ‘공유 / 파일에 저장’을 누르면 iPhone이나 Android의 시스템 공유 메뉴를 통해 파일 앱, 클라우드, 메일 등으로 보낼 수 있습니다.

6. 보안

문서 데이터는 ScanBox 서버로 전송하지 않습니다. OCR·PDF 엔진은 버전을 고정하고 최초 SHA-256 지문을 잠근 뒤 앱 전용 캐시에서 실행합니다. 문서 보정은 OpenCV 가속이 실패해도 내장 호환 엔진으로 계속 사용할 수 있습니다.
